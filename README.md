# 黄金ETF实验室

看板：https://wccwcc20260703.github.io/gold-etf-lab/

现金账户、只做日内、收盘清仓。首版覆盖华安518880、国泰518800、易方达159934和博时159937，测试五类常见信号及两类退出纪律，共40个标的与规则组合。交互方式参考沪电实验室，使用独立的黄金ETF数据、规则和账户。

**当前没有通过前瞻门槛的高胜率模型，默认状态为空仓观察。** 已取得的真实5分钟行情仅有2026-09-16至2026-11-06，共32个完整交易日、每只1536根。更长日线只作背景，不补造分钟成交。研究结果会随新数据持续积累，历史赢家不自动升级。

## 使用

看板支持选择ETF、候选规则、日期、本金、佣金、最低收费和滑点，重新计算账户；可点击日线查看该日真实分钟K线、模拟买卖点、现金与持仓账本，并下载成交CSV。全量候选含失败结果见`docs/all-trials.csv`。

```sh
npm run build
npm test
python3 scripts/account_audit.py
python3 -m http.server 8786 --directory docs
```

只依赖Node 22和Python标准库。图表ECharts 6.1.0随仓库提供，许可证见`docs/ECHARTS-LICENSE.txt`；不需要API密钥、账户登录或券商权限。

`npm run build`可从已保存的标准化分钟和日线档案离线重建。需要公开行情增量时运行`python3 scripts/fetch_data.py`；按顺序请求4只ETF的5分钟与日线，每次间隔1秒，不连接BaoStock。不成功时退出并保留最后成功发布的看板。

## 方法

- 五类：均价偏离回归、均价收复、早盘区间突破、顺势回踩、布林带/RSI反转。精确条件见`docs/engine.js`及看板。网格和折溢价只列为后续研究，不伪造缺失的历史IOPV检验。
- 决策只读取已完成K线；按下一根开盘加不利滑点模拟。买入100份整数倍，0.001元价格单位。每次成交不超过上一根5分钟量的1%，无量或接近10%涨跌停的同价K线不假定可成交。没有盘口排队或逐笔成交，实际可成交性仍有局限。
- 默认本金10万元；每次持仓不超过净资产50%；含估算费用的单笔计划风险约0.15%。不加杠杆，不卖空，不摊平补仓。每日最多3轮，连续2轮亏损后停止开仓，日内亏损达到0.60%时尝试退出。
- ATR只取当前交易日已完成的最多14根K线真实波幅均值。均衡组1.5ATR止损、1.5R止盈、最多12根；小目标组2ATR止损、0.8R止盈、最多6根。两组止损距离均限定0.15%–0.60%。止损以K线完成后判断，不能保证按触发价成交。
- 14:20后不生成开仓信号，14:50开始清仓。无法平仓时保留暴露并终止该次模拟，不能把未成交的卖单记成已清仓。
- 佣金默认双边万2.5、最低5元；股票印花税与股票过户费为0。滑点单边2bp并按0.001元向不利方向取整。另以单边增加5bp重放成本压力；由于仓位、出场触发和风控可能改变，压力结果不必逐项单调。
- 胜率按完成的一买一卖计算，盈利须扣费。没有信号的日子不算胜局。回撤按每根5分钟收盘估值，现金不计利息，不把底仓上涨混进日内收益，不做短样本年化推断。
- T+0场内卖出资金通常当天可再次交易、下一交易日可取。现金赎回属于一级市场交收，和在交易界面直接卖出不同。

## 冻结与持续研究

初始32日按时间顺序划为训练至2026-10-20、选择至2026-10-28、后段观察其后。只在训练盈利且至少10轮、选择盈利且至少5轮的候选中按选择段每轮收益择优；本次没有候选过筛，预先指定顺势回踩均衡组作后续影子记录，仍维持空仓。

`data/freeze.json`保存2026-11-06截止时点、固定分段、模型、成本、执行引擎哈希与规则哈希。未来新数据不会改写分段或自动重选模型；引擎变更会停止旧版本推进，必须明确新研究版本。历史观察段已经在本轮研究中查看，不宣称是完全独立的新证据。

从冻结截止日之后，每个新完整交易日累积盘后影子模拟。主ETF单独满足至少60个新交易日、100轮完成交易、扣费胜率≥60%、盈利因子≥1.2、正收益、5分钟最大回撤≤3%、滑点压力后仍盈利、无清仓失败，才标记达到研究升级门槛。四只高度相关ETF不合并凑样本。这些门槛是研究纪律，不是对未来收益的保证。

GitHub Actions每个工作日北京时间15:37尝试获取数据、重建、验证、保存档案并发布GitHub Pages。休市日不新增模拟交易，运行时间可能排队。数据源修订不静默覆盖已存分钟，保留原档案并记录修订计数。工作流只做公开数据研究，没有真实下单，也没有个人账户和外部通知。

## 证据与限制

`data/archive/`、`data/daily/`保存标准化源行情；`data/quality.json`保留源响应哈希、完整日与分钟收盘核对；`docs/account-audit.json`为独立Python Decimal价格、费用、现金和持仓核对回执。测试覆盖全部40个真实数据组合的账本守恒、前缀因果一致性、清仓失败留痕、资金不足及小样本升级阻断。

首版没有历史盘口、逐笔成交、可靠历史IOPV和同步海外黄金/汇率因子。国泰黄金ETF2026年4月存在份额合并，历史日线以不复权保留；本次分钟窗口不跨该日，模型每日重新计算指标，不拿份额尺度跳变充当收益。现有4只ETF每只32个交易日的分钟最终收盘与同源日线差异超过1跳均为0，但这只是同源一致性，未完成独立供应商分钟核验。

公开规则和研究来源链接在看板的数据证据区。方法的通用逻辑来自常见技术分析框架，具体参数是本次研究假设，不是黄金ETF已被证实的高胜率参数。

## 沪金趋势实验室（新增）

每笔入场记录60–100强度分、逐因子贡献、确认图形、ATR止损、目标、风险预算和费用。强度分不是成功概率。另使用该次入场前已平仓的同模型、同分数组交易，至少30笔后才输出经验胜率与Wilson区间。最终90–100组包含100分。v1.1仅修正此分组边界并添加历史频率注释，没有改变交易参数和决策；首次冻结存于`data/futures/protocol-history/`。
